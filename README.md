# 🚀 Meu Portfólio Pessoal | Davi Germanetti

> *"A tecnologia não é apenas sobre escrever código, mas sobre resolver problemas e impactar a vida das pessoas."*

Bem-vindo(a) ao repositório do meu portfólio web! Este projeto foi desenvolvido para centralizar minhas experiências, projetos e contatos em uma interface moderna, intuitiva e agradável de navegar.

---

## 🌟 Sobre o Projeto

Mais do que apenas um site institucional, criei este espaço como uma **vitrine viva** da minha evolução no desenvolvimento software. Aqui busco unir o rigor técnico da **Engenharia de Computação** com o cuidado visual em **UI/UX**, oferecendo uma experiência imersiva através de um tema dark moderno com iluminação e partículas dinâmicas.

### 🎨 O que você vai encontrar no site:
* **Sobre mim:** Uma breve apresentação da minha jornada aos 20 anos, meus estudos acadêmicos e minha paixão por inovação.
* **Projetos em Destaque:** Uma galeria dos principais sistemas que desenvolvi (como o *TaskManager*), permitindo testá-los ou ver seu código.
* **Contato Direto:** Um formulário prático integrado com envio direto para o **WhatsApp**, facilitando o networking de forma rápida e eficiente.

---

## 🛠️ Tecnologias Utilizadas

Para a construção deste portfólio, optei por uma estrutura leve, performática e sem dependências pesadas e desnecessárias:

* **HTML5:** Estruturação semântica e acessível.
* **CSS3:** Estilização moderna, responsividade completa para mobile/desktop, efeitos de *glow*, gradientes e layout em Flexbox/Grid.
* **JavaScript (ES6+):** Manipulação de DOM e lógica para envio de mensagens via WhatsApp.
* **Git & GitHub:** Controle de versão.
* **Render / Vercel:** Hospedagem e deploy contínuo.
